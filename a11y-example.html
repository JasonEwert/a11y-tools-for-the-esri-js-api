Custom A11y tools for the Esri Maps SDK for JavaScript

Your web map application has access to limitless data, it can query the names, classifications, sizes, and status of all features within its extent. This information is often hidden behind map clicks, drawn as symbols, or written as labels.

What if you don't use a mouse? What if you can't see the map? How can we use the data present in our maps to tell a story?

Dynamic map alt text

The map-alt-text.js tool can be used to query state, county, and city names. These data are then used to build a map description. The map description is presented to the user in an aria-live region, ensuring that it is read by the screen reader as the map updates.

This example is querying feature services published by Esri. It can be repurposed to query other Esri feature services.

In addition to describing the map's content, it provides a description of the map scale. When using the map's default hot keys, the aria-live region is updated with the panning or zooming direction.

Keyboard access to map clicks

In addition to the default hot keys, this tool adds a map click event that's triggered by the enter or space bar keys. This map click is executed at the very center of the map, symbolized by a crosshairs symbol.

The crosshairs symbol and hot key instructions are displayed only when the user is using the keyboard to interact with the map. Use of the mouse will remove these visuals.

The map's hotkeys are disabled by tabbing off of the map canvas.
